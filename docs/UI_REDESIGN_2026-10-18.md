# 电影感办公室悬疑界面 · 2026-10-18

用户已确认整套统一重设计：开始页、HUD、设置、暂停及结算。采用 UI/UX Pro Max 设计资料，按游戏情境筛选，具体决策见 `design-system/MASTER.md`。

## 可见变化

- 开始页使用真实办公室场景、中文大标题和纵向行动菜单；有未结束的存档时优先显示“继续上次旅程”，无存档时优先“开始下班”。DOM 顺序与视觉、键盘顺序一致。
- 深墨色、暖白、琥珀色统一按钮、章节列表、暂停、失败、结局、授权、说明和素材来源。沿用本地系统字体和现有 SVG 图标，没有新增远程资源。
- HUD 按楼层、时间、警戒、当前行动分组；教学与目标可收放，小屏默认收起教学，触屏操作保留足够空间。
- 设置拆成画面、操作、触屏、声音、辅助五类，内容独立滚动，底部“完成”保持可见。支持方向键、Home/End 切换分类，键位重绑冲突在弹窗内显示。
- 加载和载入失败沿用统一设计；尊重系统与游戏内减少动态、高对比度和键盘焦点。

## 工程边界与维护

纯视图在 `src/ui/views/`；GameUI 负责事件与游戏连接；SettingsManager 继续拥有设置验证与持久化。分类监听返回清理函数，弹窗替换或关闭时释放。样式拆为 tokens、game、menu、hud、settings、tutorial 六层。主要职责与非显然行为保留注释。

游戏规则、引擎、人物、办公室模型、资源许可、存档结构及自动画质算法没有修改。没有新增依赖、图片、网络字体、模糊滤镜或持续装饰动画。保留旧交付包，修改前 62 个文件及 SHA256 清单位于 `backups/before-ui-redesign-20261018/`，恢复备份不放入交付包。
