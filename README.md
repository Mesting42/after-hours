# 准点下班 · AFTER HOURS

浏览器 3D 第三人称斜俯视潜行游戏。冷色的 27 层办公室、尚未结束的会议和暖色电梯出口；没有战斗，只需安静地回家。

## 启动

需要 Node.js 22.12+（本机验证版本 22.20.0）和 npm。

```powershell
cd 'D:\Min\原创游戏\准时下班'
npm install
npm run dev
```

开发地址：<http://localhost:5186/>。同一局域网的手机/平板可用本机 IP 和 5186 端口访问；开发服务器绑定 `0.0.0.0`。端口被占用时明确报错，不自动使用其他端口。

```powershell
npm run build
npm run preview
```

构建输出在 `dist/`；生产预览：<http://localhost:4186/>。部署时上传整个 `dist`，包括所有子目录。支持静态子路径部署；不能直接双击 HTML，需要 HTTP 服务。

## 完整旅程

| 章节 | 主线 | 主要风险 |
| --- | --- | --- |
| 01 开放办公区 | 关闭电脑 → 取工牌 → 解除门锁 | 固定巡逻与工位遮挡 |
| 02 会议室走廊 | 阅读便签 → 取访客证 → 解除门锁 | 玻璃隔断无法遮挡视线 |
| 03 茶水与打印区 | 打印机供电 → 启动打印，离开并取件 → 解除门锁 | 打印噪声会吸引调查 |
| 04 人事与安保 | 读取口令 → 授权工牌 → 解除安保门锁 | 快速安保主管与间歇监控 |
| 05 大厅与电梯 | 恢复供电 → 呼叫并等待电梯 → 进入 | 最后一道安保巡逻 |

每章有宽走廊和较暗的边缘路线；文件柜、实墙、隐藏点和工作伪装点提供不同潜行方法。任务需要物品/许可，出口是实际有碰撞的门。新区域入口自动保存检查点；重试保留已完成任务并重置巡逻，避免重复劳动。

第一章提供持续的五步新手教学：移动 → 关机 → 拿工牌 → 刷卡开门 → 前往出口。地面金色箭头使用实际玩家碰撞体寻路，绕开墙体和家具；目标上方有金色指针与名称标记。教学面板显示当前操作、目标距离和下一步，靠近时显示实际绑定的互动键，触屏改为提示点击互动按钮。完成任务后自动更新目标，进入第二章时收起教学。

继续或重试会根据已完成的任务恢复引导，不要求重做已完成步骤。辅助设置「显示任务提示」可关闭/重新开启教学；「减少非必要动态」保留静态箭头和目标标记。

普通模式提供宽容的发现速度；硬核模式提升感知、巡逻和调查压力。两种难度都能重试，没有永久失败。两个结局分别为「回家的人」和「无声的专业人士」。

设计目标是首次探索约 20–30 分钟；当前尚未完成真人首玩计时验收。开发验证使用定位/模拟时间工具，不能作为正常通关时长依据。

## 操作

| 桌面 | 功能 |
| --- | --- |
| WASD / 方向键 | 相对镜头八方向移动 |
| Shift | 按住快走，声音更大 |
| C / Ctrl | 切换蹲伏，降低可见度与声音 |
| E | 互动、取消互动、离开隐藏 |
| Q | 全局一次性声音干扰，投向角色前方 |
| H | 进入或离开附近隐藏点 |
| 鼠标拖动 / 滚轮 | 旋转镜头 / 缩放 |
| Esc | 暂停 / 继续 |

触屏：左侧摇杆移动；拖动场景右侧旋转镜头；快走需按住，其余按钮单击。支持多指 Pointer Events、横竖屏、动态视口与安全区。放大页面不被禁用。

标准手柄：左摇杆移动，右摇杆镜头，A 互动，B 蹲伏，X 干扰，Y 隐藏，LB 快走，Start 暂停。手柄代码已实现，实体设备尚未验收。

警戒分段：0–24 无察觉，25–49 怀疑，50–74 调查，75–99 即将发现，100 确认发现。隐藏前需先脱离持续注视；工作伪装对部门领导最有效，对安保较弱。监控指示灯红色为工作、绿色为短暂停歇。

游戏时间从 17:55 开始，按 3 倍真实时间推进。18:00 加密巡逻；没有因为时间流逝而直接判负的倒计时。失焦切到其他应用/标签会自动暂停。

## 设置与存档

图形、抗锯齿、阴影分辨率、灯光、粒子、贴图采样、渲染比例、后处理、帧率显示、镜头、触屏、音量、标准手柄与辅助选项均可设置，支持键位重绑。

存储键：`after-hours.settings.v1` / `after-hours.save.v1`。保存当前区域的安全检查点、任务、工牌/许可、教程、难度、时钟、一次性干扰、结局与版本。启动会验证存档，损坏/不兼容时安全恢复；存储不可用时仍可玩，但不能保证跨刷新保留。

不同地址/端口对应不同 localStorage。开发 5186 的测试存档不会影响生产预览 4186。重玩章节或新游戏会替换当前旅程，界面会提示；解锁章节保留。

## 工程结构

```text
src/
  main.ts                     入口、本地资源载入与错误恢复
  game/
    Game.ts                   系统装配、帧循环和任务推进
    types.ts                  跨模块领域契约
    data/levels.ts            五章布局、交互依赖、领导配置和难度
    scenes/OfficeWorld.ts     建筑布局、碰撞、导入家具与电梯
    scenes/TutorialGuide.ts   有界箭头池、目标指针与地面路线渲染
    entities/                 玩家、领导有限状态机、导入骨骼角色
    systems/                  视觉、声音、导航、警戒、输入、存档、时钟等
    systems/TutorialSystem.ts 第一章教学进度，基于真实移动与任务奖励
    systems/GuideRoutePlanner.ts 独立教学寻路，逐段检测玩家碰撞
  ui/                         语义 HTML 菜单、HUD、设置与弹窗
  ui/TutorialOverlay.ts       教学文案、触屏提示与目标名称投影
  styles/game.css             自适应、触屏、安全区与减少动态
  styles/tutorial.css         五步教学面板、目标标签与横竖屏布局
  qa/DevHarness.ts            仅开发环境可见的测试夹具
public/assets/                本地 GLB、布局/时序配置、纹理、音频与字体说明
scripts/generate-assets.mjs   可重复生成原创素材
tests/systems.test.ts         核心规则测试
```

人物使用四款独立 CC BY 4.0 骨骼 GLB，家具由 Modern Office Environment 拆分并实例化，建筑与功能装置保留本地几何；材质共享，资源全本地加载。只渲染当前与邻近区域，只有当前区领导更新 AI。声音事件和音频/粒子使用有界池；导航是手工布局上的 A* 区域图。实墙/高柜使用 Babylon Raycast 遮挡，玻璃不遮挡视觉。菜单/暂停减少渲染频率。

默认 WebGL 2，Babylon 在不支持时允许 WebGL 1。未启用可选 WebGPU。桌面 60 FPS、手机 30 FPS 是目标，不是所有硬件的性能保证。

## 验证与素材

```powershell
npm test                 # 核心规则
npm run assets:generate   # 重新生成原创本地素材
npm run build            # TypeScript 检查 + 生产构建
npm run qa               # 构建产物、资源、文档与测试夹具排除检查
```

详细证据与待验收项见 [QA_CHECKLIST.md](QA_CHECKLIST.md)；逐项来源与授权见 [ASSET_SOURCES.md](ASSET_SOURCES.md)。

## 2026-10-17 模型替换

四个人物和办公室均为 CC BY 4.0，原 S1 Free Standard 与付费 P2 已排除。游戏菜单和 dist/licenses 保留署名、来源、许可与改动记录。source-assets 保留原始下载，public/assets/models 保存本地优化派生文件。

## 2026-10-17 游玩性能优化

默认开启「自动调节画质，优先流畅」。遇到持续低帧率时逐级降低内部渲染分辨率、阴影、后处理和额外灯光；不会改写已保存的手动画质选项。可在设置关闭自动调节；开启「显示帧率」可同时查看实际内部渲染尺寸。新人物、办公室、玩法和存档格式保留。

已停止不可见角色/导入模板动画，缓存当前区域遮挡网格和动作查找，固定静态变换并保留活动门体，精简教学路线碰撞检测与冗余渲染缓冲。详细测量、持续表现和限制见 [性能验证记录](docs/PERFORMANCE_2026-10-17.md)。本机测试有提升，持续稳定 60 FPS 尚未达到；独立 Chrome/Edge 和真实设备仍待验收。
